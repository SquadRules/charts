# SquadRules Helm Charts

Helm charts for deploying SquadRules MCP server on Kubernetes.

## Charts

- [`charts/mcp`](charts/mcp/) — SquadRules MCP server

## Installation

```sh
helm install squadrules-mcp oci://ghcr.io/squadrules/charts/mcp --version <VERSION>
```
